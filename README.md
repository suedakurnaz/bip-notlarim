# BiP Notlarım · Konsept prototip

BiP Night 2026'da **Taş Kağıt Makas** takımının hazırladığı tasarım önerisi. Proje BiP'teki "Kendime mesaj" sohbetini not, liste ve hatırlatıcı alanına çeviriyor. Kişi ve grup profil sayfaları da prototipin içinde.

> Bu bir konsept prototiptir. Turkcell'in ya da BiP'in resmî uygulaması değildir. Uygulamadan mesaj gönderilmez, notlar yalnızca kullanıldığı cihazda saklanır.

## Telefona kurmak
- **iPhone:** Linki Safari'de aç, sonra Paylaş → Ana Ekrana Ekle.
- **Android:** Linki Chrome'da aç, sonra ⋮ → Ana ekrana ekle (ya da Uygulamayı yükle).
